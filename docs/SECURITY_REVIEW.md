# 보안·안정성 점검과 기기 검증

검토일: 2026-11-04. 대상은 React Native 전환 코드와 공유 계산·워크플로입니다. 소스 검토와 자동 검사 범위를 기록하며, 실제 기기 침투 테스트·게임 계정 안전성 인증·배포 심사 완료를 의미하지 않습니다.

## 정보가 이동하는 범위

| 정보                | 처리·보관                              | 경계                                                                         |
| ------------------- | -------------------------------------- | ---------------------------------------------------------------------------- |
| Android 캡처 프레임 | 네이티브 메모리 처리 후 해제           | 시각·크기 메타데이터만 대기열에 저장. 현재 OCR 없음                          |
| iOS 프레임          | 네이티브 Vision 분석                   | 이미지·영상·음성 저장 없음. 자유 텍스트 전체를 브리지에 넘기지 않음          |
| iOS 텍스트 후보     | CP·HP·평가 라벨로 제한, App Group 공유 | 최대 12개·10분 유효기간·파일 크기 제한·파일 보호·백업 제외                   |
| 확인 완료 기록      | 네이티브 AsyncStorage 3                | 개체 수치·관측·이름 적용 이력. 후보 OCR 원문·이미지는 컬렉션에 저장하지 않음 |
| 웹 체험 기록        | 현재 탭 메모리                         | 새로고침 초기화. 네이티브 권한·캡처 없음                                     |
| 클립보드·내보내기   | 사용자 명시적 행동                     | 다른 앱으로 전달될 수 있음. 복사는 게임 적용 이력을 만들지 않음              |

iOS 유효기간이 지난 후보는 반환 대상에서 제외됩니다. 파일의 즉시 물리 삭제를 뜻하지 않으며 대기 결과 초기화 시 지웁니다. AsyncStorage 자체를 별도 암호화 저장소로 설명하지 않습니다. iOS 확정 컬렉션의 운영체제 백업·기기 이전 정책은 출시 전에 추가 확인해야 합니다.

현재 캡처·보유 기록 코드에 서버 업로드나 게임 서버 통신은 없습니다. Android debug의 `INTERNET` 권한은 Metro 개발 연결용이며, 릴리스의 최종 병합 권한과 네트워크 동작은 배포 빌드에서 별도 확인합니다. JSON 내보내기는 사용자가 선택한 공유 앱 또는 웹 다운로드로 전달합니다.

## 권한과 캡처 수명

- Android는 다른 앱 위에 표시 권한·MediaProjection 시스템 동의·포그라운드 서비스·알림을 사용합니다. 세션 동의 토큰을 영구 저장·재사용하지 않습니다. 알림과 앱에서 중지할 수 있습니다.
- Android 자체 화면에는 `FLAG_SECURE`, 가림 터치 필터와 지원 버전의 오버레이 숨김을 적용합니다. 다른 앱 전체를 보호하거나 게임 화면만 캡처한다고 보장하는 장치는 아닙니다.
- iOS는 사용자 시작 시스템 picker를 사용합니다. 15.1–26은 ReplayKit 확장, 27 이상은 ScreenCaptureKit 경로입니다. App Group과 두 타깃의 서명 설정이 필요합니다.
- iOS 세션은 최대 10분·분석 최대 1fps이며 음성 캡처·녹화 출력을 사용하지 않습니다. 앱 식별 정보를 얻을 때는 대상 외 앱을 제외하고, 평가 화면 형태의 최소 텍스트만 채택합니다. 이것이 모든 다른 앱 화면의 완벽한 식별을 보장하지는 않습니다.
- 중지·일시 중지·세션 변경·OCR 취소 시 늦게 도착한 결과를 차단합니다. 기기에서 다른 앱으로 이동하기 전 시스템 표시와 중지 상태를 직접 확인해야 합니다.

## 적용한 방어

| 문제                                     | 현재 방어                                                                   |
| ---------------------------------------- | --------------------------------------------------------------------------- |
| 오인식·빈 값이 확정값으로 저장됨         | 미확인 후보 분리, 필수 종·IV 직접 확인, 범위 검사                           |
| 동일 수치의 다른 개체가 합쳐짐           | 고정 앱 ID, 기존 업데이트/새 추가의 명시적 선택                             |
| 늦은 관측·초기 로드가 최신 기록을 덮어씀 | 관측 시점 검사, 비동기 결과 세대·확인 ID 검사, 저장 성공 후 상태 반영       |
| 손상·미지원 저장이 빈 데이터로 덮어써짐  | 저장 차단·원본 보존·원본 내보내기·명시적 전체 삭제                          |
| 오래된 제안·보호 이름이 변경됨           | 정책·데이터·목록 스냅샷 재검사, 명시적 보호 해제                            |
| 복사만으로 적용 성공 처리됨              | 복사와 사용자 게임 적용 확인 분리, 웹 출처 별도 기록                        |
| 과대 JSON·대기열·자유 OCR 텍스트         | 브리지·직렬화 크기/개수 검증, 제한된 후보·텍스트, 세션 수명 제한            |
| 같은 CP·HP의 다른 IV 화면이 누락됨       | 연속 화면만 메모리 픽셀 지문으로 억제, 텍스트만으로 개체 중복 판단하지 않음 |
| 중복 시작·연타·종료 후 프레임 처리       | 네이티브 요청·세션 추적, 시간 제한·취소·자원 정리                           |

이름은 코드 포인트 12자 제한과 제어·포맷 문자 검사를 적용합니다. 게임의 실제 허용 문자와 개체 선택은 사용자가 확인해야 합니다. 앱의 `user-confirmed` 이력은 사용자의 확인 사실이며 게임 저장을 자동 검증한 결과가 아닙니다.

## 자동 검증 기록과 한계

RN UI 구현 단계에서 로컬 mobile TypeScript·웹 TypeScript·Jest·UI lint/format 통과를 확인했습니다. 테스트는 입력 오류·중복 선택·복사/적용 분리·이름 보호·웹 입력 연습·저장·브리지 등 코드 경계를 다룹니다. 최종 변경 후의 정확한 테스트 수와 결과는 해당 실행 로그를 기준으로 확인합니다.

공유 코어·워크플로, Android 캡처 크기·대기열·동의 요청 정책, iOS 최소 텍스트 필터에도 자동 검사를 둡니다. CI는 고정 커밋의 Actions와 `contents: read` 권한을 사용하며 앱 서명 키·프로비저닝을 제공하지 않습니다. RN 전환의 최종 원격 네이티브 CI는 문서 작성 시점에 완료로 기록하지 않습니다. [검사 실행](https://github.com/MinsangKwak/pogo-lens/actions)에서 대상 커밋을 확인해야 합니다.

과거 Android 셸의 빌드·감사 결과를 새 RN 앱의 검증 결과로 옮기지 않습니다. 의존성 취약점·릴리스 서명·최종 권한 검사는 배포할 트리와 빌드로 다시 수행합니다.

## 실제 기기에서 완료할 검사

| 시나리오                                      | 확인할 결과                                             |
| --------------------------------------------- | ------------------------------------------------------- |
| Android 권한 거절·재허용·동의 취소            | 무단 세션 없음, 중복 요청 없이 재시도 가능              |
| 연타·프레임 시간 초과·알림 중지               | 요청 하나만 처리, 종료 뒤 후보 채택·자원 잔류 없음      |
| 회전·앱 단위 공유·다중 창·검은 프레임         | 제한 안내와 안전한 중지, 인식 성공으로 오해하지 않음    |
| iOS 두 타깃 서명·App Group 오류               | 지원 불가 안내, 원본·후보 유출 없이 복구 가능           |
| ReplayKit / iOS 27 picker 시작·취소·대상 변경 | 선택한 세션만 유효, 이전 작업 결과 차단                 |
| iOS 잠금·일시 중지·앱 전환·10분 경과          | 처리·파일 접근·시스템 중지 상태 일치                    |
| 실제 평가 화면·다른 앱 화면                   | 최소 텍스트만 후보화, 오인식 측정, 종·IV 자동 확정 없음 |
| 저장 실패·손상·재시작·원본 내보내기           | 이전 기록 보존, 확인 전 원문 미저장, 사용자 삭제만 반영 |
| 클립보드·수동 붙여 넣기·취소                  | 복사와 게임 저장 확인 구분, 대상·문자·12자 검증         |
| 작은 화면·200% 글자·TalkBack·VoiceOver        | 입력·오류·버튼 접근 가능, 탭 이동 시 작성값 유지        |
| 반복·장시간 세션                              | 메모리·발열·배터리·중지 후 자원 해제 확인               |

현재 자동 탭·게임 입력 주입·자동 교환·접근성 서비스·IME는 구현하지 않습니다. 이런 기능을 추가할 때는 별도 위협 모델과 정책 검토가 필요합니다.
